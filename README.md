# universe

Monorepo de Club Cash In. Cada aplicación vive en `apps/` y los paquetes compartidos en
`packages/`.

## Documentación

- [`docs/`](./docs/README.md) — documentación de features que cruzan varias apps (define
  el diseño **antes** de implementarlo).
- `apps/<app>/CLAUDE.md` — cómo trabajar cada app.
- `apps/<app>/docs/` — decisiones internas de una sola app (ej. los RFC del CRM).
